# Compatible devices

Every Kindle and Bluetooth device that someone reported working or broken in the issues and pull requests of this repo and [kindle-button-mapper-rs](https://github.com/zampierilucas/kindle-button-mapper-rs), up to v3.17.4. Reports with no named model are left out. Got a device that isn't here, or a result that's different? Open an issue and it gets added.
